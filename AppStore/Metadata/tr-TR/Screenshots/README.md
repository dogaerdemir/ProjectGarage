# OtoHafıza ekran görüntüleri

`6.9-inch` klasöründeki beş PNG, iPhone 17 Pro Max iOS 27 Simulator üzerinde 1320 × 2868 piksel olarak yakalanmıştır. Saat 09:41, pil %100 ve açık görünüm sabitlenmiştir.

Sıralama:

1. Ana sayfa
2. Geçmiş
3. Belgeler
4. İstatistikler
5. Yerel araç kataloğundan marka seçimi

Görüntüler yalnızca Debug derlemesindeki deterministik mağaza verisiyle hazırlanmıştır. Bu veri ve ekran görüntüsü başlatma argümanları Release derlemesine dahil edilmez.
